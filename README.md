🚀 How to Run the Programs

1. Clone the repository

git clone https://github.com/Dinesh-Ajay/Python-Course-Work.git

2. Open the project

cd Python-Course-Work

3. Check your Python version

python --version

4. Run a Python file

python filename.py

Replace "filename.py" with the Python file you want to execute.
